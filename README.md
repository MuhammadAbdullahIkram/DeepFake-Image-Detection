# Deepfake Image Detection Using Deep Learning

## Project Overview

This project uses deep learning and computer vision to classify face images as real or fake. It uses a MobileNetV2-based model implemented with TensorFlow and Keras.

## Objectives

* Classify face images into real and fake categories.
* Apply image preprocessing for deep learning.
* Explore transfer learning using MobileNetV2.
* Evaluate the trained model using classification metrics.

## Technologies Used

* Python
* TensorFlow and Keras
* MobileNetV2
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab and Jupyter Notebook

## Project Structure

* `deepfake_image_detection.ipynb` — notebook containing the project implementation.

## Dataset

The project uses a real-versus-fake face image dataset. The dataset files are not included in this repository; refer to the notebook for dataset setup and loading instructions.

## How to Run

1. Open the notebook in Google Colab.
2. Follow the dataset setup instructions in the notebook.
3. Run the cells in order.
4. Review the model evaluation results.

## Limitations

Predictions may be incorrect. This project is an educational demonstration and should not be treated as definitive proof that an image is authentic or manipulated.
